# HotPepperPodcast Starter Media License

The WAV files and `cover.png` artwork in this directory are original generated assets. The WAV files are original synthetic tones generated by
`scripts/generate_starter_media.py`. They contain no external recordings,
samples, or downloaded material.

They are dedicated to the public domain where that is recognized. Otherwise,
they are released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
No attribution is required, though keeping this file with the assets is
appreciated.

`ASSET_MANIFEST.json` records each WAV file's format, duration, SHA-256 digest,
provenance, and license metadata. `ARTWORK_MANIFEST.json` records the cover
artwork dimensions, digest, provenance, and license metadata.
